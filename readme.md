# WP AI Enum Tool

An AI-assisted WordPress security assessment tool designed for controlled testing environments.

This project performs:
- WordPress user enumeration using real-world techniques (e.g., REST API exposure, author archive routing)
- Basic weak credential detection (lab environments only)
- AI-powered analysis and structured vulnerability summarization

This tool is intended strictly for ethical testing on self-hosted or intentionally vulnerable WordPress instances.
